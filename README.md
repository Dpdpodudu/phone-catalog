# Phone Catalog - Modern E-Commerce Application

A fully responsive, interactive e-commerce web application for browsing and purchasing mobile devices and gadgets. Built with modern web development practices, this project features dynamic routing, robust state management, and a clean, pixel-perfect user interface tailored for an optimal shopping experience.

## 🚀 Live Preview

Experience the live website: [Live Demo](https://dpdpodudu.github.io/phone-catalog/)

## 🎨 Design Reference

The project UI was built precisely according to a professional design mockup. 
View the original design here: [Figma Design](https://www.figma.com/file/T5ttF21UnT6RRmCQQaZc6L/Phone-catalog-(V2)-Original)

## 💻 Technologies Used

**Core:**
* **React** – UI component library for building dynamic interfaces
* **TypeScript** – Strict static typing for robust, error-free code
* **SCSS** – Advanced styling, variables, and mixins

**Architecture & Tools:**
* **BEM Methodology** – (Block, Element, Modifier) for maintainable and scalable CSS architecture
* **Vite** – Next-generation frontend tooling for lightning-fast builds and HMR
* **npm** – Package manager
* **GitHub Pages** – Hosting and deployment
